01 / 打开就能玩

这是一个完整的 HTML 文件，无需安装。粒子画面不依赖外部素材，离线也可旋转、缩放、换色与切换造型。建议使用较新的 Chrome、Edge 或 Safari。

02 / 一只手的三种动作

  • 手掌朝向镜头：慢慢握拳收拢，张开手掌让粒子扩散。
  • 只伸出食指，其余三指弯曲：左右移动食指控制旋转，上下移动控制俯仰。
  • 保持单食指姿势，整只手移近或远离镜头，控制画面远近。以首次检测到的手掌大小为基准，也可重新校准。

前后距离使用手掌在画面中的大小估算。尽量保持掌面朝向镜头，避免手指被遮挡。手离开画面后，视角保持。

03 / 摄像头与联网

点击「启用摄像头手势」并允许摄像头。识别使用 MediaPipe，本机分析画面，不上传视频。运行库、WebAssembly 和手部模型均由当前网站提供，无需另外连接 Google 或国外 CDN。

直接打开 HTML 可体验粒子画面。完整摄像头识别请通过 HTTPS 网站或本机 localhost 服务运行，并一同保留 vendor 资源目录。手机文件预览器可能不执行网页脚本；普通 HTTP 地址通常不能使用摄像头。

04 / 其他操作

拖动旋转，滚轮缩放，双指捏合缩放；面板滑块控制扩散。「体验呼吸」是自动演示，不是摄像头识别。全屏不可用时可隐藏面板获得沉浸视图。千里江山与地球为程序生成的艺术化造型。
